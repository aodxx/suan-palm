# ตรวจเสน่ห์และ UX — สวนปาล์ม

อัปเดต: 2026-10-26 · สาขา `design/charm-polish`

เป้าหมายรอบนี้: ให้ผู้ใช้รู้สึกว่าแอป "ตอบสนองและมีชีวิต" โดยไม่แตะสูตรคำนวณ, element IDs, LocalStorage schema หรือรูปแบบไฟล์ส่งออก

## ที่ปรับในรอบนี้

| จุดที่พบ | สิ่งที่ทำ | ไฟล์ |
|---|---|---|
| เปิดแอปมาเจอแผนที่ว่างโดยไม่รู้ว่าเริ่มตรงไหน | การ์ดต้อนรับกลางแผนที่ (ข้อความต่างกันระหว่างมือถือ/เดสก์ท็อป) ใบปาล์มไหวเบา ๆ หายเองเมื่อเริ่มวาด; ปุ่ม + ส้มบนมือถือมีวงแหวนเต้นชวนกด | `index.html`, `css/style.css`, `js/app.js` (`is-empty-plot`) |
| กด "สร้างจุดปลูก" แล้วจุดโผล่พร้อมกันทั้งหมด ไม่รู้สึกว่าเกิดอะไรขึ้น | จุดผุดเป็นคลื่นตามแถวใน ~0.9 วินาที (เฉพาะตอนสร้างใหม่และไม่เกิน 800 จุด) | `createTreeMarker`, `generateGrid` |
| ตัวเลขจำนวนต้นกระโดดทันที | นับขึ้นจากค่าเดิมและเด้งเล็กน้อย | `setAnimatedTreeCount` |
| สร้างจุดสำเร็จแล้วเงียบ (บนมือถือสถานะอยู่ในหน้าเครื่องมือที่ซ่อนอยู่) | แจ้งสำเร็จบนแผนที่ (ติ๊กถูก) + สั่นเบา ๆ; ปักมุมแปลงก็สั่นเบา ๆ | `showMapToast(...'ok')`, `buzz` |
| ผู้ใช้ไม่รู้ว่าเมื่อไหร่พร้อมส่งออกรายงาน | จุดส้มบนแท็บ "รายงาน" เมื่อมีจุดปลูกและยังไม่ได้ส่งออก | `data-ready` |
| จุดปลูกแบน ๆ จุดแดงไม่สะดุดตา | ลูกปัดเขียวมีมิติ + ขยายเมื่อชี้ + จุดแดง (ใกล้เกินไป) เต้นเตือน | `.tree-dot` |
| หัวแอปเรียบ ไม่มีตัวตน | แบนเนอร์เขียวไล่เฉด มีแสงส้มผลปาล์ม; ไอคอนหัวการ์ดเป็นป้ายสีอ่อน | `.app-header`, `.card h2 .ic` |
| ปุ่มไม่มีความรู้สึกตอนแตะ | ปุ่มยุบเล็กน้อยตอนกด (`scale`) | `button:active` |
| แถบนำทางล่างบอกหน้าปัจจุบันแค่เส้นบาง ๆ | เพิ่มแคปซูลรองหลังแท็บปัจจุบัน | `.map-bottom-nav` |
| หน้าจอเปิดแอป (splash) จากไอคอนเป็นสีขาวจัด | `background_color` เป็นเขียวอ่อนของธีม | `site.webmanifest` |

ทุกแอนิเมชันเคารพ `prefers-reduced-motion` (CSS ลดเวลาเป็น ~0, JS ข้ามการนับขึ้น/จุดผุด)

## ที่พบและแก้แล้วในรอบถัดมา (สาขา `fix/offline-and-cleanup`)

1. **ออฟไลน์** — เพิ่ม `sw.js` + `js/pwa.js`: แคชไฟล์ของแอปและไลบรารี CDN (Leaflet, Turf, jsPDF, html2canvas) ไฟล์ของแอปใช้เครือข่ายก่อนเพื่อได้เวอร์ชันใหม่เสมอ ไม่มีสัญญาณจึงใช้ที่แคช; ภาพแผนที่ไม่แคช; แจ้งบนแผนที่เมื่อสัญญาณหาย/กลับมา. ข้อจำกัด: ยังต้องมีสัญญาณเพื่อโหลดภาพแผนที่ใหม่และสร้าง PDF (ตามเดิม)
2. **ลบโค้ดค้างจาก UI เก่า** — `activateCategory`, ตัวฟังแท็บ, ส่วนอัปเดต `#workflowSteps`/`#nextStepHint`, และโค้ดแผ่นล่าง (`setSheetCollapsed`, `SHEET_KEY`) รวม ~100 บรรทัด; `updateWorkflow` เหลือเฉพาะเปิด/ปิดปุ่มสร้างจุดและเรียก `updateMapFlow`
3. **favicon** — เอา SVG ขนาด ~2.1 MB ออกจาก `<head>` ใช้ PNG 32 px (ไฟล์ SVG ยังอยู่ในรีโป แต่ไม่ถูกโหลดแล้ว)
4. **ไอคอน maskable** — แยกเป็นไฟล์ `assets/icons/maskable/` (พื้นเขียว เนื้อหาอยู่ใน safe zone ~78%) และแยก `purpose` เป็น `any` / `maskable`
5. **สถานะบันทึก** — ชิป "บันทึกในเครื่องแล้ว" บนแผนที่ (มือถือ) แสดงสั้น ๆ หลังบันทึกอัตโนมัติ

## ที่ยังไม่ได้ทำ

- โหมดคอนทราสต์สูงสำหรับใช้กลางแดด
- คำแนะนำสั้น ๆ ครั้งเดียวเรื่องลาก/ลบจุดหลังสร้างจุดปลูกครั้งแรก
- self-host ไลบรารีจาก CDN (ตอนนี้แคชไว้แล้วจึงใช้ออฟไลน์ได้ แต่ครั้งแรกยังโหลดจาก CDN และไม่มี SRI)

## ที่ยังไม่ได้ตรวจ

เทสต์อัตโนมัติ 25 ข้อผ่าน แต่ยังไม่ได้เปิดดูในเบราว์เซอร์/Android จริง จึงควรตรวจด้วยตาก่อนประกาศใช้ โดยเฉพาะ: ตำแหน่งการ์ดต้อนรับบนจอเล็กและแนวนอน, ความลื่นของจุดผุดบนเครื่องรุ่นต่ำ, วงแหวนบนปุ่ม + ว่าไม่ซ้อนกับเมนูครึ่งวงกลม, การลงทะเบียน service worker บน GitHub Pages (HTTPS) และการเปิดแอปตอนปิดสัญญาณ
