# 🌴 สวนปาล์ม — Palm Planting Planner

เว็บวางแผนการปลูกปาล์มแบบสามเหลี่ยมด้านเท่า ระยะ 9 × 9 × 9 เมตร ทำงานฝั่งผู้ใช้ทั้งหมดด้วย Leaflet.js และ Turf.js ไม่ใช้ Backend ไม่ต้องล็อกอิน และไม่เก็บข้อมูลแปลงบนเซิร์ฟเวอร์

## วิธีใช้งาน

เครื่องมือทั้งหมดแสดงต่อเนื่องอยู่ในหน้าเดียว ไม่ต้องสลับแท็บหรือเปิดแผงซ่อน บนมือถือแผนที่เป็นพื้นที่หลัก พร้อมสรุปพื้นที่/จำนวนต้น ปุ่มตำแหน่งและชั้นแผนที่ เมนูปุ่ม + สำหรับวาด/สร้าง และทางลัดไปเครื่องมือกับรายงาน; เลื่อนลงเพื่อเข้าถึงเครื่องมือทั้งหมดที่ยังแสดงในหน้าเดียว บนเดสก์ท็อปแสดงเครื่องมือในคอลัมน์ข้างแผนที่

1. ในส่วน **ข้อมูลแปลง** ใส่ชื่อแปลง แล้วใช้เครื่องมือรูปหลายเหลี่ยมมุมซ้ายบนของแผนที่เพื่อวาดขอบเขต พื้นที่จะแสดงในหมวดเดียวกัน
2. หากต้องการระบุศูนย์กลางแปลง ให้กด **ชี้ตำแหน่งกึ่งกลางแปลง** แล้วแตะจุดกลางบนแผนที่ ตำแหน่งมือถือเป็นวงกลมสีน้ำเงินและแยกจากตำแหน่งแปลง; หมุดแปลงเป็นสีส้ม
3. ปรับ **ระยะห่างระหว่างต้น** (3–20 เมตร, ค่าเริ่มต้น 9), มุมหมุน, ระยะขอบ และราคาต้นกล้าในส่วน **ตั้งค่าการสร้างกริด** ระบบคำนวณตามสูตรสามเหลี่ยมด้านเท่า เมื่อเปลี่ยนระยะหลังสร้างจุด ระบบจะถามยืนยันก่อนล้างกริดเดิม
4. เมื่อมีขอบเขตแล้ว ปุ่มหลัก **สร้างจุดปลูกปาล์ม** จะเปิดให้กด ระบบจะคำนวณกริดอัตโนมัติและแสดงจำนวนจริงในส่วน **สรุปจำนวนต้น**
5. ลากจุดสีเขียวเพื่อปรับตำแหน่ง จุดที่ใกล้กว่าระยะตั้งค่าจะแสดงสีแดง แตะจุดเพื่อเลือกลบ และใช้ **เลิกทำการลบต้น** เพื่อกู้คืนจุดล่าสุด
6. ส่วน **รายงานและส่งออก** รวม PDF, พิมพ์รายงาน, CSV และ GeoJSON; PDF/พิมพ์ต้องใส่ชื่อแปลงและสร้างจุดปลูกก่อน CSV/GeoJSON ใช้ส่งข้อมูลไปวิเคราะห์ต่อ

แถบขั้นตอนด้านบนแสดงสิ่งที่ควรทำต่อจากข้อมูลจริง ปุ่มที่ใช้ไม่ได้จะแสดงคำอธิบายเมื่อชี้/โฟกัส การล้างแผนทั้งหมดอยู่ด้านล่างในส่วน **วิธีใช้และข้อมูล** และต้องยืนยันก่อนทุกครั้ง

ระบบบันทึกข้อมูลอัตโนมัติไว้ใน LocalStorage ของอุปกรณ์ ได้แก่ ชื่อแปลง ค่ากริด ราคาต้นกล้า Polygon หมุดกึ่งกลางแปลง พิกัดมือถือ และจุดปลูกที่ลากปรับแล้ว เมื่อเปิดหรือรีเฟรชหน้าเว็บ ระบบจะกู้คืนข้อมูลล่าสุดให้โดยอัตโนมัติ ข้อมูลนี้อยู่เฉพาะในเบราว์เซอร์/อุปกรณ์นั้น ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ หากเปลี่ยนอุปกรณ์หรือเคลียร์ข้อมูลเว็บไซต์ ข้อมูลจะไม่ย้ายตามไปด้วย ให้กด **ล้างทั้งหมด** เมื่อต้องการลบข้อมูลที่บันทึกไว้ในเครื่อง

บนมือถือ แผนที่ใช้พื้นที่ราว 72% ของความสูงหน้าจอและมีตัวเลขสรุป/คำสั่งด่วนลอยอยู่บนแผนที่; ด้านล่างยังมีเครื่องมือทุกส่วนต่อเนื่องในหน้าเดียวและเลื่อนขึ้นลงได้ บน Desktop แสดงคอลัมน์เครื่องมือข้างแผนที่

ระบบจะไม่ขอสิทธิ์ตำแหน่งทันทีเมื่อเปิดเว็บ ให้ผู้ใช้กดปุ่ม **📍 อนุญาตและใช้ตำแหน่งของฉัน** เองเมื่อพร้อม หากไม่อนุญาต ระบบจะใช้กรุงเทพฯ เป็นมุมมองเริ่มต้น และยังวาดแปลงใช้งานต่อได้ตามปกติ ตำแหน่งที่อนุญาตจะใช้ในเบราว์เซอร์เพื่อ reverse geocoding และใส่ข้อมูลตำบล/อำเภอ/จังหวัดในไฟล์ที่ดาวน์โหลด

ชื่อสถานที่มาจากข้อมูล OpenStreetMap ผ่าน Nominatim จึงอาจไม่มีข้อมูลตำบลในบางจุด หรือใช้ชื่อเขต/แขวงตามรูปแบบของพื้นที่จริง ระบบมี fallback และจะไม่หยุดทำงานหากข้อมูลที่อยู่ไม่ครบ

หมายเหตุแผนที่: ภาพดาวเทียม Esri บางพื้นที่อาจไม่มีข้อมูลในระดับซูมสูงสุด ทำให้ผู้ให้บริการส่งภาพสีเทา “Map data not yet available” ระบบจึงตั้งให้ใช้ภาพระดับ z18 ขยายต่อเมื่อซูมถึง z19 เพื่อไม่ให้แผนที่หาย หากต้องการตรวจสอบถนนหรือสถานที่เพิ่มเติม สามารถเปิดชั้น “แผนที่ถนน (OSM)” จากปุ่ม Layers ได้

### การดาวน์โหลด PDF

กรอกชื่อแปลงหรือเจ้าของแปลง ซึ่งเป็นข้อมูลบังคับ แล้ววาดพื้นที่และสร้างจุดปลูกให้เรียบร้อย จากนั้นกดปุ่ม PDF ระบบจะสร้างไฟล์เดียวที่มีภาพแผนที่พร้อมจุดปลูกและเส้นขอบแปลงสีเหลืองเข้มในหน้าแรก และตารางสรุปพื้นที่ จำนวนต้น ระยะห่างระหว่างแถว และพิกัดในหน้าที่สอง ข้อความภาษาไทยใน PDF ถูกวาดเป็นข้อความจริงด้วยฟอนต์ Sarabun ที่ฝังในไฟล์ ไม่ใช่ภาพตัวอักษร จึงคมชัดและค้นหา/คัดลอกได้ดีขึ้น การสร้าง PDF ต้องเชื่อมต่ออินเทอร์เน็ตเพื่อโหลดไลบรารี แผนที่ และบริการระบุชื่อสถานที่จาก CDN/แผนที่

## วิธีนำขึ้น GitHub Pages

1. สร้างหรือใช้ GitHub repository แล้วอัปโหลดไฟล์ทั้งหมดตามโครงสร้างนี้ โดยให้ `index.html` อยู่ที่ root
2. ไปที่ **Settings → Pages** ใน repository
3. เลือก **Deploy from a branch**, branch `main`, folder `/ (root)` แล้วกด Save
4. รอ GitHub สร้างเว็บไซต์ แล้วเปิดลิงก์ที่ GitHub Pages แสดงให้

## โครงสร้างไฟล์

```text
suan-palm/
├── index.html
├── css/
│   └── style.css
├── assets/
│   ├── fonts/              # ฟอนต์ Sarabun สำหรับฝังใน PDF
│   └── icons/              # ไอคอน favicon, Android และ iOS หลายขนาด
├── js/
│   ├── calculator.js
│   ├── app.js
│   └── exporter.js
├── tests/
│   └── regression.test.cjs
└── README.md
```

## ตรวจ regression

ใช้ Node.js รุ่นที่รองรับ `node:test` โดยไม่ต้องติดตั้ง dependency เพิ่ม:

```bash
node --test tests/regression.test.cjs
node --check js/app.js
node --check js/calculator.js
node --check js/exporter.js
```

รายงานผลทดสอบและรายการตรวจที่ยังต้องทำบน Android จริงอยู่ใน [`docs/PHASE-0-5-ACCEPTANCE.md`](docs/PHASE-0-5-ACCEPTANCE.md)\n\nแผนพัฒนา UX รอบถัดไปที่อิงภาพตัวอย่างและแอปอ้างอิงอยู่ใน [`docs/ROADMAP-UX-REFERENCE-BASED.md`](docs/ROADMAP-UX-REFERENCE-BASED.md) (Phase 6–10)

หน้าเว็บเชื่อมโยง favicon, ไอคอน Apple Touch และ `site.webmanifest` แล้ว ผู้ใช้สามารถเลือก **เพิ่มไปยังหน้าจอหลัก** บน Android หรือ iOS ได้ โดยใช้ไอคอนชุดเดียวกันในขนาดที่เหมาะสม

## เครดิตไลบรารี

- [Leaflet](https://leafletjs.com/) และ [Leaflet.draw](https://github.com/Leaflet/Leaflet.draw) สำหรับแผนที่และการวาดพื้นที่

- [jsPDF](https://github.com/parallax/jsPDF) สำหรับสร้างไฟล์ PDF และ [html2canvas](https://github.com/niklasvh/html2canvas) สำหรับจับภาพแผนที่และเรนเดอร์ภาษาไทย
- ฟอนต์ [Sarabun](https://fonts.google.com/specimen/Sarabun) จาก Google Fonts/Open Font License สำหรับแสดงและฝังภาษาไทยใน PDF
- แผนที่ดาวเทียมจาก [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9) และแผนที่ถนนจาก [OpenStreetMap](https://www.openstreetmap.org/)
